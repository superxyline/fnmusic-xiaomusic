# 部署指南：小爱音箱播放飞牛音乐收藏（v2 单容器 FPK）

> 效果：对家里的小爱音箱说 **「播放本地收藏歌曲」**（或「播放列表本地收藏」），
> 音箱即以随机顺序播放 NAS 上飞牛音乐的收藏列表。收藏有增减时约 5 分钟内自动同步。
>
> v2 单容器版：一个安装包、一个端口（58091）、一个 Web 界面。安装包内置全部镜像，
> 安装过程**不需要访问外网**。安装后打开应用，按向导三步完成配置。

## 一、方案原理（30 秒版）

```
小爱音箱 --"播放本地收藏歌曲"--> 小米云 --> xiaomusic（内嵌在本容器 /xm/，轮询对话、匹配口令）
                                              |
xiaomusic 播放网络歌单「本地收藏」<== 桥接服务（同进程）定时推送歌单 JSON
                                              |
小爱音箱 <== /proxy/music 转发 <== 桥接 /play?guid= <== 飞牛音乐 /track/stream
```

- **xiaomusic**（pip 安装、内嵌为子应用 mount 在 `/xm/`）：与小爱音箱通信、口令轮询、播放控制。
  扫码登录复用其官方 `qrcode_login`（米家 App 扫码 → passToken → auth.json）。
- **桥接服务**（`bridge-v2/`）：飞牛音乐登录/收藏同步/歌单生成/音频流代理 + 三步向导 UI。
  把「飞牛 API 逆向」的风险隔离在一个薄层里。

## 二、前置条件

| 项目 | 要求 |
| --- | --- |
| NAS | 飞牛 fnOS，已安装并正常运行**飞牛音乐**（端口默认 5666） |
| 音箱 | 任意小爱音箱（向导里勾选，型号自动识别） |
| 账号 | ① 小米账号（米家 App 扫码或账号密码）② 飞牛音乐登录账号密码 |
| 网络 | 音箱、NAS 在同一局域网；记下 **NAS 的局域网 IP**（本指南示例：192.168.31.26） |
| 端口 | 58091 未被占用 |

## 三、安装 FPK

### 方式 A：App 中心手动安装（推荐）

1. 飞牛桌面 → **App 中心** → 右上角「手动安装」
2. 选择 `xiaomusic-fnmusic-0.2.fpk`
3. 安装向导只需填两项：**NAS 局域网 IP**（默认 192.168.31.26）、**应用端口**（默认 58091）
4. 等待安装完成（约 1-2 分钟，主要是加载内置镜像），应用状态变为「运行中」

### 方式 B：命令行安装

```bash
cat > xm-install.env <<'EOF'
nas_ip=192.168.31.26
bridge_port=58091
EOF
sudo appcenter-cli install-fpk /path/to/xiaomusic-fnmusic-0.2.fpk -e xm-install.env -v 3
```

## 四、三步向导（安装后第一次打开）

浏览器打开 **http://NAS_IP:58091**（或点桌面「小爱音箱」图标）：

### 第 1 步：登录小米账号

- **账号密码**：填小米账号（手机号/邮箱）和密码，登录
- **扫码登录**（推荐）：展示二维码，用**米家 App** 扫码确认
- 登录成功自动进入下一步（拉取账号下的设备列表）

### 第 2 步：勾选小爱音箱

- 列出账号下所有设备（名称 + 型号），勾选要接管的小爱音箱（可多选）
- 保存后进入下一步

### 第 3 步：连接飞牛音乐

- 自动扫描 NAS 上的飞牛音乐服务（发现后自动填入地址）
- 填写**飞牛音乐账号密码**（就是登录飞牛音乐库用的那套）
- 点「完成，开始使用」——自动拉取收藏、生成乱序歌单、推送口令配置

### 完成页

显示收藏数、歌单数、推送状态、口令帮助。对小爱说：

> **「播放本地收藏歌曲」**

## 五、语音口令

| 口令 | 效果 |
| --- | --- |
| **播放本地收藏歌曲** | 播放收藏歌单（随机） |
| **播放列表本地收藏** | 同上（显式歌单名，识别更稳） |
| 下一首 / 上一首 / 停止播放 | 播放控制 |
| 随机播放 / 全部循环 / 单曲循环 / 顺序播放 | 切换播放模式 |
| 刷新列表 | 重新加载歌单（改了收藏不想等同步时用） |

## 六、日常维护

- **收藏同步**：每 5 分钟自动比对；完成页可点「立即同步」
- **看日志**：飞牛 Docker → 容器 fnmusic-xiaomusic → 日志（xiaomusic 与桥接日志都在这）
- **改配置**（NAS IP/端口）：App 中心 → 应用设置 → 配置，保存后自动重启生效
- **重新走向导**：完成页 → 「重新配置」按钮（保留小米登录态）
- **高级设置**：完成页底部「xiaomusic 高级设置」链接（/xm/，原版 xiaomusic 界面）
- **升级 FPK**：卸载后装新包，小米账号绑定自动迁移（v1 双容器版的数据也会迁移）

## 七、故障排查

| 现象 | 排查 |
| --- | --- |
| 向导第 1 步登录失败 | 账号密码错/风控（短时间内多次登录会触发，等 10-30 分钟）；扫码登录一般不受影响 |
| 扫码后没反应 | 二维码 2 分钟过期，刷新重扫；确认扫的是「米家 App」而不是微信/相机 |
| 口令没反应 | ① 确认第 2 步勾选了音箱 ② 换个说法「播放列表本地收藏」 ③ 看容器日志有没有匹配记录 |
| 音箱提示无法播放 | 完成页看「最近错误」；飞牛升级可能导致接口变化，把日志发我 |
| FLAC 收藏播放失败 | 音箱型号可能不支持无损（L05B/L05C/LX06/L16A），看完成页转码状态 |
| 播放几秒就跳下一首 | 单曲取流失败被探路跳过；看容器日志该 guid 的取流结果 |
| 小米登录莫名失效 | 小米服务端会吊销长时间不用的 token——重新走一遍向导第 1 步（扫码最快） |
| 换了 NAS IP | App 中心 → 配置里改 NAS IP，保存自动生效 |

## 八、重新打包 FPK（开发用）

```bash
# 1. 本地打骨架（不含镜像）
tools/fnpack.exe build --directory fpk-v2-src
python scripts/repack_fpk.py xiaomusic-fnmusic.fpk xiaomusic-fnmusic-v2-base.fpk

# 2. 上传骨架到 NAS，一键构建镜像 + 合成最终 FPK
python scripts/nas_ssh_put.py xiaomusic-fnmusic-v2-base.fpk /home/Aadmin/
# NAS 上执行：bash /home/Aadmin/nas_v2_rebuild_all.sh
# （解包 → docker build fnmusic-xiaomusic:local → docker save → 注入骨架 → 重打）

# 3. 下载最终 FPK
python scripts/nas_ssh_get.py /home/Aadmin/xiaomusic-fnmusic-0.2.fpk ./
```

关键经验（fnOS FPK 时序坑）：
- `install_init` 阶段包已解压到 `$TRIM_TEMP_TPKFILE` 目录，可提前 `docker load` 预置镜像
- appcenter 先起容器后跑 `install_callback`，回调末尾必须 `docker compose -p <app> up -d` 重建
- uninstall 会删 compose 引用的镜像 + 删 /var/apps 目录，但 **@appshare 数据区保留**
- env 文件用裸字段名（`nas_ip=` 而非 `wizard_nas_ip`）；安装必须 `-v <卷索引>`

## 九、已知限制（如实说明）

1. **飞牛 API 非公开**：接口来自社区逆向，fnOS 大版本升级可能导致变动——只需更新桥接服务重新出包
2. **xiaomusic 项目已停止维护**（作者转做 songloft，但 songloft 不管小爱音箱）
3. **小米账号风险**：轮询对话记录是社区 7k+ star 成熟方案，官方建议该账号不要同时绑定摄像头
4. **小米 token 会过期**：小米服务端策略，过期后重新走向导第 1 步即可（数据不丢）
5. **进度拖动**：网络歌曲经 xiaomusic 代理播放，拖动进度会从头开始
6. **容器内无 Node.js**：xiaomusic 的 JS 插件功能不可用（日志有 warning，不影响核心功能）

## 十、文件结构

```
│   ├── fnmusic_client.py         # 飞牛 API 客户端（登录/收藏/流/authx 签名）
│   ├── static/wizard.html        # 三步向导 + 完成页
│   ├── Dockerfile / requirements.txt
│   └── test_integration.py       # 本地集成测试
├── fpk-v2-src/                   # v2 FPK 打包源码
│   ├── manifest / config / cmd / wizard / ICON*.PNG
│   └── app/docker/fnmusic-app/   # 应用源码（与 bridge-v2 同步）
│       └── app/docker/docker-compose.yaml（单服务）
├── scripts/                      # 打包/部署/测试脚本
│   ├── fnpack 相关：repack_fpk.py（修 cmd 权限位）
│   ├── NAS 构建：nas_v2_rebuild_all.sh / nas_build_final_v2.sh / nas_prep_v2_images.sh

└── docs/
    └── 部署指南.md                # 本文件
```
